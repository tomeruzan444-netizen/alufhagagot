# אלוף הגגות — אתר סטטי

מיגרציה של `https://roofschamp.co.il` מוורדפרס (Elementor) לאתר HTML סטטי,
תוך שמירה מלאה על התוכן, ה-URLs, התמונות והמטא־דאטה.

---

## מבנה התיקיות

```
build/            ← האתר המוכן להעלאה. זה כל מה שצריך לעלות לשרת.
  index.html
  <slug-בעברית>/index.html      166 עמודים
  wp-content/uploads/...        התמונות במיקום המקורי + גרסאות .webp
  assets/css|js|fonts/
  sitemap.xml  robots.txt  404.html  _redirects  _headers  .htaccess

src/              ← מקורות העיצוב (CSS/JS) שמהם build נבנה
tools/            ← סקריפטים: זחילה, פירוק, בנייה, אימות
deploy/           ← קונפיגורציית nginx להפניות
_source/          ← ה-HTML הגולמי שנזחל + מניפסטים (לא להעלאה)
_shots/           ← צילומי מסך לבדיקה
```

## הרצה מחדש

```bash
npm install
node tools/parse.js          # HTML גולמי  → בלוקים סמנטיים
node tools/build.js          # בלוקים      → 166 עמודי HTML
node tools/seo-files.js      # sitemap / robots / redirects / 404
node tools/verify.js         # השוואה מלאה מול האתר המקורי
node tools/serve.js          # שרת מקומי על http://127.0.0.1:8181
node tools/audit.js          # בדיקת גלישה אופקית בדסקטופ/טאבלט/מובייל
node tools/shots.js          # צילומי מסך
```

`tools/fetch.sh` + `tools/images.js` + `tools/download-assets.js` מריצים זחילה
מחדש מהאתר החי (לא נדרש אלא אם התוכן במקור השתנה).

## לפני העלייה לאוויר — חובה

### 1. חיבור הטפסים
כרגע `formAccessKey` ב-[tools/site.config.js](tools/site.config.js) הוא `YOUR_ACCESS_KEY`.
עד שיוחלף, כל שליחת טופס נופלת אוטומטית ל-WhatsApp כך שאף ליד לא הולך לאיבוד.

לחיבור אמיתי: להירשם ב-web3forms.com (חינם), להעתיק את המפתח,
להחליף בקובץ הקונפיג ולהריץ `node tools/build.js`.

### 2. בדיקת ההפניות
`build/_redirects` (Cloudflare/Netlify), `build/.htaccess` (Apache),
`deploy/nginx-redirects.conf` (nginx). לבחור לפי האחסון בפועל.

### 3. אחרי ההעלאה
- להגיש את `sitemap.xml` מחדש ב-Google Search Console
- להסיר את ה-sitemaps הישנים של Rank Math (`sitemap_index.xml`, `page-sitemap.xml`…)
- לעקוב אחרי "כיסוי" ו"ביצועים" ב-Search Console במשך 4–6 שבועות

## מה שופר

- HTML לעמוד: ‎178KB → 47.5KB (‎-73%)
- בקשות CSS/JS: ‎64 → 3 (‎-95%)
- תמונות: WebP במקביל למקור, ‎-69% משקל
- גופן Assistant מאוחסן מקומית (7KB לתת-הקבוצה העברית), **נאכף על כל התוכן**
- H1 יחיד בכל עמוד (במקור היו 7 עמודים ללא H1 ו-2 עם כפול)
- שאלות ותשובות כ-`<details>` נטיבי, ללא JS
- ווידג'ט נגישות עצמאי (~4KB) במקום תוסף AccessibleWP
- כפתור חיוג/ווטסאפ קבוע במובייל
- תפריט נפתח ב-hover בדסקטופ, בלחיצה במגע/מקלדת
- סרטון היוטיוב נטען רק בלחיצה (חוסך ~700KB ומונע קוקיז צד-שלישי בטעינה)

### הערה על ה-CSS של ווידג'טים מותאמים
המחשבון, הטיפ היומי וטבלאות ההשוואה הודבקו במקור כמסמכי HTML שלמים, כולל
`body { font-family: Arial }` שדרס את הפונט של **כל** האתר.
[tools/scope-css.js](tools/scope-css.js) מכווץ כל `<style>` כזה לתוך העטיפה
`.embed` שלו ומסיר את הצהרות הפונט, כך ש-Assistant יורש לכל מקום.

כל המקפים הארוכים (`–` en dash, ‎2,144 מופעים) הוחלפו במקף רגיל `-` בכל האתר:

`href`/`src` נשמרים בייט-בבייט. `node tools/seo-audit.js` מאמת שנשארו 0.

## נקודות פתוחות (דורשות החלטה שלך)

1. **תמונה שבורה** — `/wp-content/uploads/2024/11/אלוף-הגגות-9.png` מחזירה 404
   **גם באתר המקורי**, ומופיעה ב-4 עמודים כולל `/איטום-גגות/`.
   ההפניה נשמרה כפי שהיא; צריך להעלות את הקובץ מחדש.

2. **כותרות meta כפולות** — 3 עמודים חולקים את הכותרת
   *"איטום גגות - איטום וזיפות כל סוגי הגגות במחיר משתלם ✅"*:
   `/איטום-גגות/`, `/איטום-גגות-בבית-שמש/`, `/איטום-גגות-בקדימה-צורן/`.
   נשמרו 1:1 לפי ההנחיה, אבל שני עמודי הערים כנראה קיבלו את הכותרת בטעות
   וכדאי לתת להם כותרות ייחודיות.

3. **קישור שגוי בפוטר המקורי** — הטקסט "איטום גגות בצפון" הופיע פעמיים,
   כשאחד מהם מקשר ל-`/איטום-גגות-בדרום/`. תוקן בקונפיג לרשימת אזורים מסודרת.

4. **`/איטום-גגות-בבנימינה-2/` — עמוד עם זהות סותרת.**
   ה-URL וה-H1 אומרים **בנימינה**, אבל ה-title וה-meta description אומרים
   **טירת הכרמל**. במקביל קיימים כבר `/איטום-גגות-בבנימינה/` ו-`/איטום-גגות-בטירת-הכרמל/`
   נפרדים, כך שהעמוד הזה מקנבל את שניהם.
   **לא נגעתי בו** — כל תיקון (לשנות את הכותרת לבנימינה, או להפנות 301) משנה
   למה העמוד מדורג, וזו החלטה שתלויה בנתוני התנועה שרק לך יש. תגיד לאן ואבצע.

5. **`/איטום-גגות-בבית-אריה-2/`** — עמוד שני על אותה עיר, תוכן שונה מ-
   `/איטום-גגות-בבית-אריה/` (נוצר 03/2026 מול 10/2024). קניבליזציה של אותה
   מילת מפתח. שווה לשקול מיזוג או 301.

6. **9 תמונות ללא alt** ו-9 תיאורי meta קצרים מ-70 תווים (רמת חומרה בינונית,
   מחוץ למה שביקשת לתקן). הרשימה המלאה ב-`_source/seo-audit.json`.
